# Abyss Diver Girls（Godot 4 可玩原型）

用 Godot 4.4 或更新版本（4.6 / 4.7 也可）打开 `project.godot`，按 F5 运行。不需要任何美术资源。

## 操作
- WASD 移动 · 鼠标瞄准（上半身独立转向）
- 左键 左臂开火 · 右键 右臂开火
- 空格 冲刺 · Q 背部技能
- E 搜索容器（点击物品在容器与货舱之间转移）
- R 燃料电池 · H 维修包 · T 呼叫运输机 · Esc 暂停

## 玩法
在机库组装机甲、把消耗品放进出击货舱 → 空投 → 搜刮 → 在能源耗尽前到撤离点（或用信标呼叫运输机）。
撤离成功带回一切；失败则失去身上全部机甲模块和货物。

## v0.5 模块化建模架构

机甲由**互相解耦的独立模块**拼装而成，每个模块一个建模脚本，只通过标准接口对接：

```
底盘 legs_* ──HP-C1 腰部回转座圈──▶ 躯干 core_*
躯干 core_* ──HP-A1 臂部挂点法兰──▶ 左臂 / 右臂 arm_*
          ├─HP-B1 背部双导轨────▶ 背部挂载 back_*
          └─HP-G1 动力舱────────▶ 动力炉 gen_*
```

- `scripts/modules/kit.gd`：接口规范、插座 `socket()` / 插头 `module_root()`（母座与公插头外观一一对应）、公共材质与零件
- `scripts/modules/<模块id>.gd`：17 个模块各自独立建模（4 底盘 / 3 躯干 / 4 武器 / 3 背部 / 3 动力炉）
  - 模块根节点原点 = 插头接合面中心；躯干只声明插座位置，任何臂 / 背 / 动力炉都能装上
  - 新模块：在 `data/ext/equipment.gd` 的 MODULES 登记 + 新建同名脚本；没有脚本时自动生成带标准插头的通用占位件
- `scripts/mech_visual.gd` 变成纯装配器：
  - `build(loadout)` 按装配树拼装
  - `apply(root, loadout)` 只热插拔变化的模块；换躯干时臂 / 背 / 动力炉自动转插到新躯干同名插座；换底盘时躯干座圈移到新高度
  - `explode(root, t)` 爆炸视图，显示各接口铭牌
  - `scatter(root)` 机体损毁时各模块在接口处崩脱散落
- 机库：换装只拆下 / 装上对应模块（分离 + 对接回弹动画），顶部「拆解视图」按钮切换爆炸图
- 测试：`godot --headless --path . -- --modular` 遍历所有槽位 × 所有模块热插拔，校验接口、插座、炮口（21 次换装 0 错误）
- 截图：`--gallery --view=explode0..3`（爆炸图）、`--view=dead0..3`（损毁散落）

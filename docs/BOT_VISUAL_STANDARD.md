> **目标基准**：Red Button《B.o.T》(Battle of Titans, Unreal Engine 4) 硬派军工写实机甲与战地环境。

### 视觉判据（Pass/Fail Statements）
1. **单次线性色调映射**：全链路仅经一次 ACES Filmic（或无二次肩部削顶的线性 LUT）映射到屏幕，受光沙地、混凝土与金属倒角高光干净通透（`p95 >= 195`），绝不发灰发闷。
2. **电介质军漆 vs 裸钢导体严格分离**：完好装甲漆面为消光/半消光重防蚀漆（`metallic <= 0.04`, `roughness 0.56–0.70`），棱边磨损处经 `1–2cm` 深色防锈底漆圈（`metallic = 0.0`, `roughness = 0.85`）硬跳变至高反光冷轧裸钢（`metallic >= 0.90`, `roughness 0.22–0.32`）。
3. **分件多色涂装与高饱和战术点缀**：单台机甲具备主装甲色（橄榄绿/石板灰/沙褐）+ 次级散热/肩舱对比色（暗铁红 `armor_oxide` / 深冷灰 `armor_sub`）+ 黑铁油润内构（`dark`）+ 镀铬/紫铜液压件（`chrome`/`copper`）+ 高辨识黄黑警示/白字战术编号贴花（`decal`）+ 凹腔百叶反应堆发光核心。
4. **暗部零死黑剪影**：机甲背光面与腿部内构在天空半球漫反射 + 地面反弹光下清晰可读（每颗铆钉、油管、减震簧可辨，`crush <= 2.2%`），同时地面投射清晰硬朗的平行光主阴影（阴影亮度约为受光地面的 `38%–46%`）。
5. **地表与路缘自然过渡**：沥青呈日晒风化灰蓝（线性反照率 `0.14–0.20` 而非煤黑 `0.03`），泥沙按高度图优先填入路面裂缝与路肩碎石带，消除干净棕色积木路缘石与高饱和亮青脚底光圈。

## 3. 建模几何与装配规范（`tools/mech_kitbash/`）

1. **修复 UV 投射与纹素密度**：
   - 移除 `_assign_box_uv` 中导致 `tile_u > 1.0` 纹理拉丝的 `min(1.0, nu)` 硬截断；
   - 区分 **米制连续密度映射 (`uv_mode="world_meter"`, `~0.65 UV/m`)** 与 **等比框选映射 (`uv_mode="framed"`)**，彻底消灭椭圆拉伸螺栓。
2. **大倒角铸造/轧制轮廓 + 7:3 疏密对比**：
   - 主装甲壳体棱边倒角提升至 `24–55mm`（大转折采用 `segments=2` 圆润铸造倒角），确保 `25–35m` 战术镜头下依然拉出清晰金属亮边；
   - 严格保持 70% 大倾角干净装甲面 + 30% 关节凹腔高密机械细节（外露长行程镀铬液压缸、紫铜减震箍、编织油管、凹陷发光散热扇环）。
3. **补齐主力出镜模块 GLB**：
   - 升级起步与主力躯干（`core_scout`、`core_std`、`core_heavy`、`core_assault`、`core_m1a2_sepv3`），并补齐高频实战/机库底盘、武器、背挂与动力炉（`legs_biped`、`legs_biped_assault`、`legs_titan`、`arm_mg`、`arm_gatling`、`arm_ac30`、`arm_hmg`、`arm_slug`、`back_cargo`、`back_missile` 外露橙头战术导弹架、`back_shield`、`gen_cell`、`gen_reactor` 凹陷弧形发光散热百叶核心、`gen_diesel`），使机库与实战主力配装 100% 统一在高精度 Trim v2 世代。

## 4. 机库与战区光影、反射、地表融合规范

1. **战区光照与反射（`raid.gd` + `weather.gd`）**：
   - 色调映射统一为 **单次线性 ACES Filmic**（移除 LUT 二次高光削顶），校准曝光与天空亮度；
   - 桌面端天空辐照度升级至 `Sky.RADIANCE_SIZE_256` 并配置战区 `UPDATE_ONCE` 静态 `ReflectionProbe`，让裸钢掉漆与镀铬活塞反射出清晰冷暖天际线；
   - 桌面高画质启用 **4 级联平行光阴影**（收紧近景级联、`shadow_normal_bias = 0.28`、`shadow_blur = 0.85`），让反应装甲砖、炮管与天线在机体上投出锐利自阴影；
   - 地表泥土/沙砾/沥青提升至真实物理线性反照率（`0.14–0.36`），沥青改为风化灰蓝并强化裂缝泥沙高度混合，路缘石叠加破损风化细节；机甲脚底高饱和青圈改为极低透明细刻度战术环。
2. **整备机库（`hub.gd` BAY 03）**：
   - 压低机甲正后方 `BAY 03` 橙色逆光窗眩光，主聚光灯调至 `~38°` 侧前掠射角雕刻正面装甲凹凸与掉漆棱线，补齐左后冷钢轮廓光与转盘格栅暖色地坑反弹光，将死黑率从 `36%` 压至 `< 12%`。

# Web 导出

已添加 Godot 4.7.2 Web Release 导出，输出为 `build/web/index.html` 及同目录资源。兼容渲染器 WebGL 2，单线程、不依赖 SharedArrayBuffer，桌面和移动纹理压缩格式同时包含。桌面/Android 渲染器保持原配置。

## 运行

```powershell
python tools/serve_web.py
```

电脑浏览器打开 `http://127.0.0.1:8765/`。不能直接双击 HTML（`file://`）。本地服务器会为预压缩文件发送正确的 Content-Encoding 和 MIME 类型。单线程版本不强制 COOP/COEP，但服务器同时提供这些头以便后续线程版测试。

同一局域网手机测试可使用 `python tools/serve_web.py --bind 0.0.0.0 --port 8766`，然后在手机打开 `http://电脑局域网地址:8766/`；需要系统防火墙允许入站。这只用于本地测试，公开部署应使用 HTTPS。当前没有对外发布。

重新导出：`./tools/export_web.ps1`。Web 模板为官方 4.7.2 `web_nothreads_debug.zip` / `web_nothreads_release.zip`，本机位置写在 Web preset；下载归档的 SHA-256 与发布 API digest 核对一致，`D:/123/tmp/godot472-web/download.json` 保存来源。

## 网页适配

- 通过 `.web` 配置选择 Compatibility，默认流畅档、60 FPS 上限；画质对应 720/900/1080 内部渲染短边上限，使用 WebGL 支持的双线性缩放。此值是预算，不是 K40 实测帧率。
- 浏览器不支持当前 ENet/UDP 联机。Web 端房间入口明确显示「网页版·单人」，网络创建/加入接口返回不可用；原生平台仍保留完整联机。
- 浏览器机库反射探针六面烘焙产生 `glBlitFramebuffer` 深度/模板格式警告，Web 端保留天空环境反射、跳过局部探针；原生探针保留。变更后浏览器机库未再报告该警告。
- 排除 `build/*`、`review/*`、测试和工具，防止把历史生成资源混进网页包。`build/.gdignore` 避免编辑器导入自己的构建输出。

## 验证与限制

使用本机 Chrome、1280×720、NVIDIA ANGLE/D3D11 后端验证；这不是手机实测。浏览器主菜单、新游戏、存档位、机库、二维地区地图、携带准备、灰港出击能够运行。IndexedDB `/userfs` 中存在存档；刷新页面后存档位仍存在并可载入。

最终精简包复测：载入刷新后保留的第二存档位，完成出击；键盘移动和按住鼠标射击输入可执行，截图确认机甲发生位移。最终日志无 JavaScript/Godot 错误及 WebGL blit 警告，仅保留首次交互前的浏览器音频自动播放提示。包文件与源码 SHA-256、范围和限制记录于 `review/web_export_manifest.json`；这不是全流程战斗或长时帧率验收。

初版进入灰港构建约 26 秒，后续空投阶段也有首次绘制开销，尚未做 Web 加载性能优化。没有把浏览器截图或桌面原生 FPS 当作 Web/K40 帧率验收。音频需首次点击/触摸解锁，这是浏览器规则；没有进行主观听音验收。

原生 `saveio` 与双进程 `coop_smoke` 通过，确认网页限制没有破坏原生存档/联机。

当前 PCK 约 366.2 MiB、WASM 约 37.7 MiB，主要载荷未压缩合计约 404.1 MiB；gzip 后传输约 **352.4 MiB**。需整包下载，仍较重，不能称为面向手机的轻量正式版。公开试玩前需要素材精简/分包、K40 浏览器 30 分钟热机及内存测试，联机则需另行实现 WebSocket 或 WebRTC 传输。

截图和日志位于 `review/web_*.png`、`review/web_browser_log.json`、`review/web_export_release.log`。本轮 Android 依赖安装因切换 Web 工作而暂停，没有宣称 Android 修补模板或 K40 优化已经完成。

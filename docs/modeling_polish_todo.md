## P0 · 场景建筑与环境世代差精修（视觉落差最大）

### 1. 城区与工业建筑告别“平铺贴图直角方盒子”（已完成：30 项精修预制包 B1-01 ~ B6-30）
- **问题现状**：录像左侧砖房与仓库仍为无厚度屋檐、无凹凸窗框的简单平铺贴图立方体，在高精度 2K PBR 机甲与巨型首领衬托下呈现明显“早期沙盘感”。
- **涉及脚本**：`scripts/buildings/*.gd`、`scripts/buildings/prefab_lib.gd`、`scripts/buildings_ext.gd`、`scripts/map_ext/poi_kit.gd`、`scripts/map_ext/landmarks.gd`、`scripts/map_ext/landmarks_boss.gd`、`scripts/raid.gd`
- **逐项精做标准**：
  - [x] **M1.1 屋顶结构化**：为全部 21 款民居、商住楼、工业厂房、变电站与地标巨构增加压顶女儿墙（Parapet）、混凝土挑檐、通风气楼、冷却水箱、涡轮风球与避雷针桁架，彻底消除生硬顶面切线。
  - [x] **M1.2 立面凹凸分层**：外墙全面实装 0.15m~0.28m 真实内凹钢框玻璃窗、防爆钢百叶、外凸承重壁柱/门式刚架、深凹导轨卷帘门、外挂铸铁逃生梯与斜拉杆门头雨棚，并统一接入 2K 红砖/模板混凝土/波纹钢法线贴图。
  - [x] **M1.3 墙根接地过渡（Skirt & AO）**：每栋建筑与工事底部实装双阶混凝土散水勒脚基座、通风百叶口、防撞护柱与沙袋胸墙，并通过 `PrefabLib` 预合并 + `MultiMesh` 顶点色分块合批保持低 Draw Call。

### 2. 道路、民用/军用车辆残骸与机甲的尺度校准（已完成：B4-16 ~ B4-20）
- **问题现状**：公路边停放的轿车/厢式车宽度仅约 `1.4m ~ 1.6m`，与 `4m` 高重装机甲及双车道宽度同框时比例偏袖珍像玩具车；路面与沙漠边缘呈一刀切直线。
- **涉及脚本**：`scripts/buildings/veh_*.gd`、`scripts/buildings/ter_road_shoulder.gd`、`scripts/raid.gd`、`scripts/map_ext/poi_kit.gd`
- **逐项精做标准**：
  - [x] **M2.1 车辆尺度与硬表面重制**：按真实重型工业/军用载具尺度（宽 `2.65m ~ 2.90m`、长 `6.1m ~ 7.5m`）实装 4 款高细节硬表面残骸（`veh_dump_truck` 重型自卸矿卡、`veh_apc_wreck` 八轮装甲运兵车、`veh_fuel_tanker` 半挂油罐拖车、`veh_armored_dozer` 装甲履带推土机），按战区智能分派。
  - [x] **M2.2 道路路肩破损过渡**：沿荒原/农田/弹坑区公路边缘实装 `ter_road_shoulder`（龟裂啃边沥青 + 错位倾倒路缘石 + 风积黄沙漫坡 + 重型履带车辙印 + 弯折波形护栏）。

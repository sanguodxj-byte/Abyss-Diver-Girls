## P0 · 场景建筑与环境世代差精修（视觉落差最大）

### 1. 城区与工业建筑告别“平铺贴图直角方盒子”
- **问题现状**：录像左侧砖房与仓库仍为无厚度屋檐、无凹凸窗框的简单平铺贴图立方体，在高精度 2K PBR 机甲与巨型首领衬托下呈现明显“早期沙盘感”。
- **涉及脚本**：`scripts/buildings_ext.gd`、`scripts/map_ext/poi_kit.gd`、`scripts/raid.gd`
- **逐项精做标准**：
  - [ ] **M1.1 屋顶结构化**：为平顶/坡顶建筑增加压顶女儿墙（Parapet）、混凝土挑檐、屋顶通风机组、锈蚀水箱与避雷针桁架，消除锐利生硬的顶面直角切线。
  - [ ] **M1.2 立面凹凸分层**：外墙增设内凹窗洞（深色玻璃 + 钢制防爆百叶/窗台板）、外凸混凝土承重柱列、卷帘门导轨与门头雨棚。
  - [ ] **M1.3 墙根接地过渡（Skirt & AO）**：每栋建筑底部增加 `0.35m` 高混凝土勒脚基座、散落碎砖/沙袋掩体及墙根接地软阴影贴花，消除建筑像积木一样“浮”在黄沙上的割裂感。

### 2. 道路、民用/军用车辆残骸与机甲的尺度校准
- **问题现状**：公路边停放的轿车/厢式车宽度仅约 `1.4m ~ 1.6m`，与 `4m` 高重装机甲及双车道宽度同框时比例偏袖珍像玩具车；路面与沙漠边缘呈一刀切直线。
- **涉及脚本**：`scripts/raid.gd`、`scripts/map_ext/poi_kit.gd`
- **逐项精做标准**：
  - [ ] **M2.1 车辆尺度与硬表面重制**：按真实军卡/装甲运兵车/重型皮卡尺度（宽 `2.4m ~ 2.9m`、长 `5.5m ~ 7.5m`）重做或通过 Meshy 生成 3~4 款高细节废弃工业载具（重型自卸矿卡、装甲运兵车、油罐拖车、工程推土机）。
  - [ ] **M2.2 道路路肩破损过渡**：在柏油路与荒原黄沙交界处增加碎裂路缘石、风沙掩埋斜坡贴花与重型履带车辙印。

## P1 · 自然地貌、植被与战场微观掩体精修

### 3. 荒原/农田散景植被与微地貌打散
- **问题现状**：尘土平原右侧农田的灌木/作物呈等距行列排布的单色暗块，拉远至 `1.8×` 战术镜头时重复感强、地面过于平坦空旷。
- **涉及脚本**：`scripts/raid.gd`、`scripts/maps.gd`
- **逐项精做标准**：
  - [ ] **M3.1 植被多尺度自然簇化**：打破规则网格抖动，改用“大株枯木/防风林残桩 + 中型耐旱沙棘丛 + 贴地干草簇”三级簇群分布，并修正远景色彩使其融入环境光照而非发黑剪影。
  - [ ] **M3.2 战场重工业残骸与微地貌点缀**：开阔荒原混入旧世界弹坑环、半掩埋输油管段、混凝土龙牙反坦克锥、倾倒高压线塔残段，既丰富视觉层次又提供真实战术掩体。

## P1 · 新巨型首领模型一体化精雕（消除拼接重复感）

### 4. 六足要塞（`citadel_behemoth`）一体化宽体主舰壳与铰接座精修
- **问题现状**：当前宽体版通过 5 个 `citadel_hull.glb` 旋转拼接获得了扎实的 `36m` 宏观宽高比，但俯视近看时五块相同舰壳的重复烟囱/舱门纹理密集堆叠，且腹底斜撑油缸与船体连接处仍用基础几何块过渡。
- **涉及资产与脚本**：`assets/models/boss/citadel_hull.glb`、`assets/models/boss/citadel_leg.glb`、`scripts/enemies/boss_modular_glb.gd`
- **逐项精做标准**：
  - [ ] **M4.1 定制原生 2:1 超宽体陆地巡洋舰一体主壳 GLB**：单独使用 Meshy 生成并减面一件原生宽扁八角重装舰壳（区分前向破障首楼、左右独立外伸炮廓耳台、后部集中式排烟动力舱），替换当前 5 件同模拼接，让俯视甲板动线干净清晰。
  - [ ] **M4.2 独立建模上股节（Femur）与下胫节（Tibia）专用资产**：拆分为专门的「重型箱型桁架上股节 GLB」+「垂直双缸液压柱与四爪驻锄巨靴 GLB」，使膝关节球头与腹底斜撑耳轴严丝合缝咬合。
  - [ ] **M4.3 炮塔击毁专属残骸模型**：为被玩家打爆的副炮塔制作专属扭曲断管/掀盖焦黑残骸网格，替代当前的整件变黑倾斜。

### 5. 浮空母舰（`sky_carrier`）机库内构与舰腹炮廓一体化精修
- **问题现状**：前腹两座副炮塔目前采用程序化圆柱吊篮下挂，前机库弹射无人机时缺少可见的内部发光导轨舱室。
- **涉及资产与脚本**：`assets/models/boss/carrier_hull.glb`、`assets/models/boss/carrier_thruster.glb`、`scripts/enemies/boss_modular_glb.gd`
- **逐项精做标准**：
  - [ ] **M5.1 舰腹流线型装甲炮廓吊舱**：建模专用斜面装甲武器挂舱，自然贴合母舰下腹部折角，消除圆筒过渡件。
  - [ ] **M5.2 贯通式无人机弹射甲板内舱**：在前首防爆门后方制作带警示灯带与弹射滑轨的内凹机库腔体，释放 `wasp` 编队时舱门滑开、导轨亮起。
  - [ ] **M5.3 涡扇进气道旋转扇叶分离**：将 `carrier_thruster` 顶部的进气涡轮风扇拆分为独立旋转子网格，悬停与俯冲时高速旋转。

## P2 · 全图鉴敌群与武器模块材质世代统一

### 6. 程序化常规虫族 / 旧首领与 PBR GLB 首领的质感对齐
- **问题现状**：目前 `excavator_titan`、`citadel_behemoth`、`sky_carrier` 已升级为 2K PBR 写实重工贴图，而部分早期常规虫群与程序化首领仍使用较光滑的程序化色块材质，同屏混战时材质颗粒度略有差异。
- **涉及脚本**：`scripts/enemies/models.gd`、`scripts/enemies/boss_models.gd`、`scripts/enemies/boss_models_ext.gd`
- **逐项精做标准**：
  - [ ] **M6.1 高频出镜精英怪（`mech_beetle`、`ironjaw`、`colossus`）Meshy PBR 化**：将体型较大、停留时间长的重甲精英敌种分批替换为带骨骼动作的减面 PBR GLB。
  - [ ] **M6.2 程序化金属/甲壳 Shader 细节补强**：为保留程序化建模的中小虫种统一叠加微表面划痕法线、边缘磨损掉漆与关节暗部 AO 顶点色。

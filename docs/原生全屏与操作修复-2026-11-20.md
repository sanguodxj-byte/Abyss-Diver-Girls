# 原生全屏、装填与瞄准修复

## 用户要求

- 全屏严重卡顿需要修复。
- 恢复有限连续发数和装填时间；用户明确不需要实体弹匣物品或补给消耗。
- 按住右键可把观察点拉到远处，玩家机体允许完全离屏；不抬高视角，瞄准移速减半。

## 修复

菜单/机库使用独立 3D SubViewport，原来按 3840×2160 原生渲染且绕过自动缩放。现在尺寸改变时更新其画质；自动档按总像素预算选择缩放，流畅/高/极致分别使用 1080p/1260p/1440p 的 16:9 等效像素预算。4K 高档内部 3D 为 2240×1260，FSR 放大；界面与文字仍为原生输出。显式 100% 原生档仍不缩放。

UI.bind_fit_panel 原先将捕获面板的 lambda 连到根视口，面板销毁后未解绑，窗口尺寸改变时持续报 Lambda capture freed。改用随面板释放的回调节点，8 轮销毁/尺寸变化回归通过。

实弹武器保留每轮有限发数、打空自动装填、R 提前装填、装填期间禁射、完成后自动补满。空货舱也可正常出击和反复装填；商店、掉落、初始配给没有弹匣物品。激光和近战保留既有能耗。旧存档中的误加弹匣在载入时按原标价返还信用点，迁移后存档重复载入不重复退款。跨区仍保留当前弹量、容量与货舱。

第三人称右键仅移动 XZ 平面的观察中心，基础远距偏移上限普通 45m、狙击 70m，侦察属性可增加范围。允许机体离屏；高度、俯角和滚轮缩放不因瞄准变化。松开恢复常规跟随。speed_mult 在既有负重/损伤修正上乘 0.5。第一人称保持原有 FOV 开镜。

## 本机验证

修补 Godot 4.7.2 Debug 源码运行时、RTX 4060 Ti、Vulkan Forward+、高画质、关闭 VSync。帧率用于比较当前本机情况，不代表手机或所有地图。

| 场景 | 修复前 FPS | 修复后 FPS | 修复后 P99 |
| --- | ---: | ---: | ---: |
| 菜单 4K 全屏 | 12.78 | 138.72 | 10.16ms |
| 机库 4K 全屏 | 24.09 | 136.62 | 11.21ms |

菜单/机库各采样 180 帧、预热 3 秒；修复收益同时包含降低内部 3D 像素和回调清理，不能视作相同原生 4K 画质的性能对比。

按用户当前存档的极致画质另测：4K 全屏菜单 120.94 FPS / P99 10.92ms，机库 124.13 FPS / P99 9.22ms；内部 3D 为 2560×1440。记录 `review/fullscreen_ultra_after.json`。

灰港 4K 全屏自动档战斗 45 秒：5899 帧，精确平均 131.07 FPS；P95≤10.9ms、P99≤13.1ms（0.1ms 桶上界）、最大 31.632ms、>33.3ms 为 0。517 次射击、14 次真实换弹，覆盖移动与右键远距观察。测试为保持压力会补充备用弹匣，并使用无敌/高能源；实际耗弹与换弹耗时照常执行。该记录来自本次规则澄清前，装填耗时与当前一致；当前不再有补充备用弹匣的测试逻辑。该短测不代替长局验收。

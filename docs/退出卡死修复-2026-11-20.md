# Alt+F4 退出卡死修复

## 根因与现场

用户报告全屏游戏无法退出。原进程 158308 无响应，连续观察线程 CPU 时间不再增长。保存所有线程栈后，使用同一源码对象文件重新链接生成地址映射；原运行时与重链接运行时的 `.text` SHA-256 完全一致，确认地址映射有效。

主线程停在 `Main::cleanup → WorkerThreadPool::exit_languages_threads` 的第一阶段等待。只读进程内存显示：工作线程 12 个，runlevel=PRE_EXIT_LANGUAGES，就绪计数 3；普通/低优先级任务队列均为空，所有 worker 均等待条件变量。现场证据：`review/quit_hang_threads.txt`、`review/quit_hang_registers.txt`、`review/quit_hang_pool.json`。

4.7.2 在切换退出阶段时广播一次唤醒。低优先级队列尚未排空时，一部分 worker 无任务可取而再次休眠；最后一批任务完成后，没有再次通知它们登记退出状态。主线程等待全部 worker 登记，睡眠 worker 等待下一个通知，形成永久等待。

## 修复

引擎 `core/object/worker_thread_pool.cpp` 的 PRE_EXIT_LANGUAGES 分支中，当任务队列排空、有线程完成退出准备登记时，唤醒尚未登记的 worker。保留原先任务完成和脚本语言退出顺序，不绕过资源清理，不添加超时强杀。

补丁：`tools/engine/godot-4.7.2-worker-shutdown.patch`。`tools/engine/build_runtime.ps1` 已同时应用该补丁与原反射探针资源释放补丁，并记录两个源码/补丁哈希。

## 验证

`tests/exit_probe.gd` 负责构建菜单、机库、暂停、第一人称等真实场景；`tools/test_exit.py` 从外部发送 WM_CLOSE、SC_CLOSE 或真实 SendInput Alt+F4，要求进程本身退出码 0。测试存档隔离。按键发送前检查前台窗口属于测试进程，避免误关其他程序；未取得焦点不能算键盘验证通过。

| 测试 | 结果 |
| --- | --- |
| 旧运行时，关闭时追加 64 个有限 native 后台任务 | 收到 CLOSE_REQUEST、完成 EXIT_TREE 后仍卡死，12 秒超时失败 |
| 新运行时，同一后台任务压力场景 | 2.782 秒正常退出 |
| 新运行时，压力场景重复 3 次 | 2.531 / 2.640 / 2.625 秒，全部退出码 0、无错误 |
| 真正 Alt+F4，第一人称全屏战斗 | 0.906 秒退出，无错误 |
| 真正 Alt+F4，全屏暂停 | 0.796 秒退出，无错误 |
| WM_CLOSE，机库 | 0.578 秒退出，无错误 |
| 机库创建/释放 4 轮 | 显存基线增长 0 MiB，无孤儿节点、无退出 Texture RID 警告 |
| native_controls | 空货舱多轮限时装填、提前装填、远距离屏瞄准、固定高度俯角、半速移动通过 |

另有一轮真实按键后台压力测试最终正常退出，但等待约 12 秒；两次重复键盘测试因前台焦点未取得而拒绝发送，不计入通过数量。普通状态与压力状态分别报告，不把后台任务时间视为固定退出耗时。

索引：`review/exit_before_busy.json`、`review/exit_after_busy.json`、`review/exit_stress_repeat*_busy.json`、`review/exit_keys_after_first_person.json`、`review/exit_keys_after_pause.json`、`review/exit_keys_after_hub.json`、`review/quitfix_hub_lifecycle.log`、`review/quitfix_controls.log`。

## 部署

新源码运行时已部署至既有 `build/runtime-patched/template_debug-source/`，因此 `启动游戏.bat`、性能监控器及手工启动均使用修复版。旧运行时保留在 `build/runtime-patched/template_debug-source-before-shutdown-fix/`，候选副本在 `build/runtime-patched/template_debug-source-quitfix/`。

新运行时 SHA-256：`C5F35288DA9786C4D4006C866C2C0A789D9210403EE005F1B67CB5B0D3F287A4`。这是保留调试检查的原生运行时，未发布外部安装包。旧卡死进程在取证后结束；没有编辑用户存档来修复退出。
